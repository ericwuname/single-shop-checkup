## 4. WP-1 · 访问控制（P0）

### 4.1 设计（已定，不要自己改方案）

**单租户访问码**：一个部署 = 一个访问码 = 一位老板。不建用户表、不做登录页的账号体系（多老板/多角色是 `docs/09` 的 M10，现在不做）。

| 配置（环境变量） | 含义 |
|---|---|
| `PUBLIC_MODE` | 真值（`1/true/yes/on`）= 公网模式；默认关 |
| `APP_ACCESS_KEY` | 访问码。公网模式下**必须设置且长度 ≥ 20**，否则服务**拒绝启动**并打印原因 |
| `ALLOWED_ORIGINS` | 逗号分隔的允许跨域来源。公网模式下**只放行这里列的**；留空 = 不发任何 CORS 放行头（同源使用，最安全）。非公网模式保持现状（`*`） |
| `ADMIN_TOKEN` | 既有，用于删除权，**不变** |

### 4.2 后端改动（文件级）

**新建 `server/access.py`**（约 120 行）：

```python
def is_public_mode() -> bool: ...          # 运行时读环境变量，不要在 import 时缓存（测试要用 monkeypatch）
def validate_public_config() -> None: ...  # 公网模式下 APP_ACCESS_KEY 缺失/太短 → 抛 RuntimeError(中文原因)
class AccessKeyMiddleware(BaseHTTPMiddleware): ...
```

`AccessKeyMiddleware.dispatch` 规则（**逐条照做**）：

1. 非公网模式 → 直接放行（行为与现在完全一致，所有旧测试不受影响）。
2. 请求方法是 `OPTIONS`（CORS 预检）→ 放行。
3. 路径是 `/docs`、`/redoc`、`/openapi.json` → 返回 **404**（不是 401，不暴露存在）。
4. 路径**不以** `/api/` 开头（即前端静态文件、`/manifest.json`、`/sw.js`、图标）→ 放行。
5. 路径是 `GET /api/health` → 放行。
6. 其余 `/api/*`：读请求头 `X-Access-Key`，用 `hmac.compare_digest(a.encode(), b.encode())` 比较（**必须恒定时间比较**，不能用 `==`）。
   - 正确 → 放行。
   - 缺失或错误 → 返回 `401`，JSON `{"detail": "需要访问码"}`，并计入失败次数（见 7）。
7. **防暴力猜测**：按客户端 IP 统计失败次数，**10 分钟内失败 ≥ 10 次 → 该 IP 返回 429**（`{"detail": "尝试太多次，请 10 分钟后再试"}`），封锁期内**即使访问码正确也返回 429**。内存字典即可，不落库。客户端 IP 取 `CF-Connecting-IP` 头（有则用），否则 `request.client.host`。
8. **访问码绝不出现在**：日志、异常信息、响应体、URL 查询串。只许走请求头。

**修改 `server/main.py`**：

- `lifespan` 开头调用 `validate_public_config()`。
- `CORSMiddleware`：公网模式下 `allow_origins` 取 `ALLOWED_ORIGINS` 解析出的列表（可为空列表），非公网保持 `["*"]`。因为 `add_middleware` 在 import 时执行，**用一个小函数 `cors_origins()` 在构造时读取环境变量**；同时测试里要能验证——允许你把中间件配置抽成 `build_cors_kwargs(env)` 纯函数来测。
- 中间件登记顺序：`ErrorLogMiddleware`（最外）→ `RateLimitMiddleware` → `AccessKeyMiddleware`（最内）。（Starlette 里**后加的在外层**，请自行核对顺序并在注释里写明依据。）
- `health()`：公网模式下**只返回** `{"status","version","db_writable","db_error"}`，**去掉** `llm`、`enabled_fields`、`enabled_metrics`、`shops`。

**核对 `server/middleware.py` 的 `ErrorLogMiddleware`**：确认它**不记录请求头**。若记录了，改掉。（M6 报告说只记方法/路径/状态码/店 id/耗时，请你实际读代码确认。）

**更新 `.env.example`**：加上 `PUBLIC_MODE`、`APP_ACCESS_KEY`、`ALLOWED_ORIGINS` 三项（值留空/占位），并写一行生成命令注释：
`python -c "import secrets; print(secrets.token_urlsafe(24))"`。

### 5.2 D2：空数据时的自相矛盾与提示堆叠

**位置**：`server/routers/report.py` 约第 599–624 行（`line2 = tone["default_verdict"]` 与 `warnings.append(...)`）。

   - 日：`"有了营业额和买菜钱，才能判断高低。"`

### 7.3 `sw.js` 规则（**逐条照做**）

1. `const CACHE = 'checkup-v1'`（每次发版手动加一，写在手册里）。
2. `install`：`self.skipWaiting()`；不做预缓存清单（资源文件名带哈希，预缓存清单要构建时生成，本轮不搞）。
3. `activate`：删除所有名字不等于 `CACHE` 的旧缓存；`clients.claim()`。
4. `fetch`：
   - 非 `GET` → 不处理（直接 `return`，走网络）。
   - 跨域请求 → 不处理。
   - 路径以 `/api/` 开头 → **不处理（必须走网络，绝不缓存接口响应）**。文件里要有一行注释明确写出这一点，且字符串 `/api/` 必须出现在代码里（验收脚本会检查）。
   - 页面导航请求（`request.mode === 'navigate'`）→ **网络优先**，失败回退到缓存里的 `/`（首页）。
   - `/assets/` 与 `/icons/` 下的静态文件 → **缓存优先**（文件名带哈希），未命中则取网络并写缓存。
5. **不使用**任何 `cache.addAll([...'/api/...'])` 之类写法。

### 7.4 注册

仅在 `'serviceWorker' in navigator` 且（`location.protocol === 'https:'` 或 `location.hostname === 'localhost'`）时注册。`controllerchange` 事件里**只刷新一次**（用一个变量防循环刷新）。整个注册过程 `try/catch`，失败只 `console.warn`，**不影响应用使用**。

### 7.5 后端静态服务

确认 `web/dist` 由后端挂在 `/` 时：`/sw.js` 返回 `text/javascript` 且带 `Cache-Control: no-cache`（Service Worker 本体不能被长期缓存）。若 `StaticFiles` 默认不带，就加一个只针对 `/sw.js` 的响应头设置（几行代码，写在 `main.py`）。
