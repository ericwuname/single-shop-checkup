## 4. M1 验收门禁（复述，四条全过才算完成）

```bash
cd single-shop-checkup
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m pytest tests/ -q                       # 门禁 1：全绿
python -m uvicorn server.main:app --port 8000    # 门禁 1：启动无报错
curl -s localhost:8000/docs                      # 门禁 1：返回 Swagger
cd web && npm install && npm run dev             # 门禁 3：手机可提交、有结果
```

| # | 门禁 | 判定方式 |
|---|---|---|
| 1 | 上面四条命令全部通过 | 终端输出 |
| 2 | **开发者本人连续 7 天在手机上录入真实数据** | 自证，不得伪造 |
| 3 | **加一个新指标只通过向 `metric_def` 插一行完成，不改任何 Python/前端代码** | **做不到即架构失败，返工** |
| 4 | 5 个指标与手工 Excel 一致（误差 <0.01） | 与 `outputs/单店人力成本体检表.xlsx` 对算 |
