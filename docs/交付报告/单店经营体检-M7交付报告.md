## 5. 诚实清单（任务书 §11 第 5 条，不许省略）

1. **gen_icons.py 没用 Pillow**（任务书 §7.1 原文"用 Pillow"）：本机当前无外网通路（代理对 pypi 返回 502、直连无 DNS 路由），Pillow 装不上。实现为**Pillow 优先 + 纯标准库兜底**（zlib+struct 手写 PNG），两层画同一形状，验收脚本 3.8 只检查 PNG 魔数与尺寸——两种来源都过。**要还原成纯 Pillow：`pip install pillow` 后重跑脚本即可**（代码路径已就位）。
2. **修图标时踩了一个字节错位 bug**：透明像素写成 4 元组再拼 alpha 变 5 字节，每行错位 1 字节/像素，症状"图标全黑"且几何函数单测全对（打桩才定位到）。修复后用"白区段 vs 几何柱坐标"断言钉住，bug 成因写进了源码注释。
3. **用例 12（CORS）TestClient 测不到**：`add_middleware` 在 import 时定格环境变量。按任务书 §4.2 允许的方式改用 `build_cors_kwargs` 纯函数断言；真实部署路径由验收脚本 1.8（先设 env 再起服务）覆盖。已在测试与 commit message 中留痕。
4. **旧组件未删**：`DailyInput/ShiftTable/ResultCard.vue` 还在仓库里（任务书 §6.3"验收通过之前不要删"——验收的最终裁定在评审窗口，故本分支不删）。**评审验收通过后的清理提交**应删除三个旧组件 + `views/` 之外残留引用。
