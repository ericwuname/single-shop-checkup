## 怎么读 `.dc.html`

- 它是设计工具的源文件，**不能直接当网页用，也不要整段复制进 Vue**。
- `<x-dc>`、`<helmet>`、`{{ … }}`、`<sc-for>`、`<script type="text/x-dc">` 是设计工具语法，忽略。
- 每个元素的 `style="…"`（尺寸、颜色、字号、圆角、间距）就是规格，照着写进 Vue 组件的 CSS。
- `<link href="https://fonts.googleapis.com/…">` 只是设计预览用。**实现时不要引外网字体**，用系统字体栈。
- 屏里的数字（4,200、32,300、34.1% 等）是**示例数据**，实现时来自 API。
- 页内链接 `Main.dc.html` 等对应实现里的三个页签。

## 设计原则（为什么长这样）

- 老板在打烊后、手忙脚乱时用：大字、大数、少输入、一屏一件事。
- 状态不只靠颜色：偏高 ↑ / 正常 ✓ / 偏低 ↓ 带图标和文字。
- 可点区域 ≥ 44px；真实的 button/input/label；图标按钮有 aria-label。
- 不出现术语、不出现英文字段名。
