# 06 · M5 自查审查任务书

> **下达方**：执行窗口（自查 —— 交付前先给自己下一道审查令）
> **审查对象**：M5 A 线交付物（M5-0 / M5-1 / M5-2 + 门禁九条）
> **目的**：**在交给蓝图窗口之前，先自己把能找到的毛病找出来。**
>
> 理由：交付报告是自己写的，天然会往好里写。不自审一遍就交出去，
> 等于让评审窗口替我做质检 —— 那是浪费评审的注意力。
> 本轮已到"打磨阶段"，所以这次审查**允许联网查证**，也**允许回头改代码**。

---

## 0. 审查原则（三条）

1. **不信自己的报告，信源码。** 每条判定必须能指到文件:行号或可复跑的命令。
2. **判定不给"基本通过"这种模糊词。** 只有四档：`PASS` / `观察` / `必修` / `阻断`。
3. **审查必须产出"我错了"的清单。** 如果审完一条都没发现，说明审得不够深，重审。

## 1. 审查维度与判据

### A. 口径正确性（联网查证，对照权威）

| # | 审查项 | 对照的权威 | 方法 |
|---|---|---|---|
| A1 | 量差 / 价差公式 | 财政部《管理会计应用指引第 302 号——标准成本法》§22 | 联网查证 + 比对 `bom_service.record_variance` |
| A2 | 出成率换算方向 | 餐饮业通行定义（净料率 = 净 ÷ 毛） | 联网查证 + 比对 `bom_service.gross_qty` |
| A3 | BOM 里的"标准价"是毛料价还是净料价 | 净料单价 = 毛料单价 ÷ 净料率 | 查证 + 检查是否可能错配 |
| A4 | 应付账龄分桶与起算点 | 通行做法（按到期日，30 天一档，**"未逾期"单独一列**） | 查证 + 比对 `supplier_service.payables_aging` |
| A5 | ABC 抽盘周期 | 循环盘点通行节奏（A 周 / B 月 / C 季） | 查证 + 比对 `ABC_CYCLE_DAYS` |
| A6 | 审批的 5% 比例阈值 | 餐饮业实际损耗率区间 | 查证 + 判断阈值是否把常态当异常 |
| A7 | 损耗率分母 | 行业三种口径（营业额 / 进货额 / 理论成本） | 查证 + 判断我选的哪个、是否要说清 |

### C. 架构纪律（这个项目的地基，破了就是返工）

| # | 审查项 |
|---|---|
| C1 | 加字段/加指标是否仍是"插一行"，零 DDL、零前端改动 |
| C2 | **账面库存是否仍是唯一实现**（不许出现第二份算法） |
| C3 | 表数守卫是否被绕过（不是改期望值糊过去，是真的该加） |
| C4 | 业务代码是否直接 import 厂商 LLM SDK（`docs/05` §9 禁止） |
| C5 | 商品编码被引用后是否仍拒绝修改（红线） |

### D. 反自欺（最重要的一组）

| # | 审查项 |
|---|---|
| D1 | 变异验证覆盖的是不是**最关键的**不变量？有没有"只挑容易红的改" |
| D2 | 有没有**不会失败的断言**（断言了一个永远成立的东西） |
| D3 | 新测试是否真的在测产品行为，还是只是在测自己刚写的函数 |
| D4 | 我修改过的老断言：是"换成新断言"还是"悄悄删了" |
| D5 | 门禁跑的是不是**当前代码**（服务重启过没有、有没有吃缓存） |

### E. 代码质量与边界

| # | 审查项 |
|---|---|
| E1 | BOM 的 `unit` 与商品库存单位不一致时会不会算错（单位错配） |
| E2 | 审批判定用的账面 vs 报告用的账面，是不是同一个口径 |
| E3 | 边界：除零、负数、空集合、超大数据量 |
| E4 | 事务边界与异常安全（半写状态、批量接口的异常吞没） |
| E5 | N+1 查询（差异报表按货品循环时的数据库往返） |
| E6 | 幂等：重复提交会不会产生重复应付/重复差异 |

### F. 产品可用性（M0 视角）

| # | 审查项 |
|---|---|
| F1 | M5-0 让老板**新增了多少录入动作**？（项目硬约束：每日新增 ≤ 30 秒） |
| F2 | "实际领用"能不能不录而自动推算 |
| F3 | 前端没展示的部分会不会让老板以为功能不存在 |

## 2. 判定档位

| 档 | 含义 | 处理 |
|---|---|---|
| **阻断** | 数字会算错 / 违反红线 / 自欺 | **本轮必须修完才能交付** |
| **必修** | 明确缺陷但影响可控 | 本轮修；修不了要写明为什么不修 |
| **观察** | 有争议或需要顶层裁定 | 登记进报告，不擅自改口径 |
| **PASS** | 有证据支持 | 写明证据出处 |
