### M3-2 · 隐性成本报表

| 项 | 内容 |
|---|---|
| **目标** | 做出产品的第一张"震撼报表"：老板填完一个月，弹出「你以为赚 X，算上这些实际是 Y」 |
| **锚点** | `server/seed_metrics.py:27 FIELD_SEEDS`、`:117 METRIC_SEEDS`、`server/routers/report.py:151 build_conclusion` |

**新增 5 个字段（月口径，走 `field_def`，零 DDL）**：

| code | label | 查证依据 |
|---|---|---|
| `staff_meal_m` | 员工餐 | 人数 × 15 元/天 × 营业天数，年约 2–3 万 |
| `tableware_m` | 餐具破损与更换 | 季度采购额汇总，年约 0.6–1.2 万 |
| `repair_m` | 设备维修 | 年度维修单据，年约 0.5–2 万 |
| `cash_diff_m` | 收银差异 / 漏单 | **流水 0.3%–1%**，年约 0.4–1.2 万 |
| `returned_m` | 退菜报废 | 退菜记录汇总 |

**新增原子量** `hidden_cost_m`（`additive`，month）= 上述五项之和。

**新增派生指标** `real_profit_gap`：老板以为的利润 − 隐性成本。
（口径由执行窗口定，但**必须能在结论里说出两个数的差额**。）

**结论话术要求**（年度档）：

> 「这一年你账面赚了 X。算上员工餐、餐具、维修、收银差异这些容易被漏掉的，实际是 Y —— 中间差了 Z。」

**验收**：3 年数据补录隐性成本后，Y3 的实际利润必须**显著低于**账面利润，且差额在结论里说出来。

### M3-3 · 账实差异报表（本产品唯一护城河）

| 项 | 内容 |
|---|---|
| **目标** | 回答用户原话："销售出库的数据能否与库存数据对得上" |
| **锚点** | 需**首次解锁新建表** —— 见下方授权 |

**🔓 M3 范围解锁（评审授权，须同步改守卫）**：

| 表 | 状态 | 用途 |
|---|---|---|
| `goods` | **解锁（M3 可建）** | 商品主数据（含单位、换算率） |
| `stocktakes` | **解锁（M3 可建）** | 盘点单 |
| `scraps` | **解锁（M3 可建）** | 报废/损耗单 |
| `suppliers` / `purchases` / `receipts` / `bom` | **仍锁定**（M3b / M4） | — |

> 表数守卫由「恰好 7 张」改为「**恰好 10 张**」，并在 docstring 写明授权依据。

**核心公式**（v1.0 §3.5）：

```
账面库存 = 上期结存 + 入库 − 出库            （系统算）
实盘库存 = 盘点录入                          （人填）
差异数量 = 实盘 − 账面
差异金额 = 差异数量 × 单价
差异率   = |差异数量| / 账面数量
```

**指标** `stock_variance_rate`（`ratio`），结论话术：

> 「账面应该剩 50 斤，实际只有 43 斤，差 7 斤 ≈ 210 元。」

**验收**：造一组"账面 100 / 实盘 93"的数据，断言差异率 7%、差异金额正确；**且差异为 0 时不出这句话**（不许制造噪音）。
