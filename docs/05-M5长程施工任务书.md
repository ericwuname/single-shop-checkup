## 3. A 线 · M5-0 · 解锁 `bom`，让账实差异变纯

| 项 | 内容 |
|---|---|
| **目标** | `账面 = 上期实盘 + Σ入库 − Σ领用 − Σ报损` 里，**"领用"这一项现在没有**。补上之后差异才等于"跑冒滴漏" |
| **锚点** | `server/models.py`（新增 `Bom` / `BomVariance`）、`server/metrics_engine.py` 账面推算处 |
| **表** | 解锁 `bom`；表数守卫 **14 → 15** |

**按 v1.0 §3 的三条修正执行**：

| # | 修正 | 公式 |
|---|---|---|
| 1 | **出成率**（漏了标准成本必算低） | `std_qty_gross = std_qty_net / yield_rate` |
| 2 | **差异拆量差 / 价差** | `量差 = (实际用量 − 标准) × 标准价`（厨房问题）<br>`价差 = (实际价 − 标准) × 实际用量`（采购问题） |
| 3 | **ABC 分类抽盘**（不要求每天全盘） | A 类（金额前 20%）每周、B 类每月、C 类每季。**只盘 A 类能抓 80% 差异** |

**验收**：
- 造一组"卖 100 份、标准用量 10kg、实际领用 11kg" → 量差正确、价差正确、总差异 = 两者之和
- 造一组出成率 88% 的品 → 标准毛料用量 = 净料 ÷ 0.88
- **改口径后 `stock_variance_rate` 必须下降**（因为领用被算进去了，差异变纯）

## 4. A 线 · M5-1 · 供应商与应付账款

> 这是用户**原始需求里的第一大块**（v0.2 §3.1），从 M1 排到现在一直没做。

| 项 | 内容 |
|---|---|
| **表** | 解锁 `suppliers`、`payables`（或把付款记进 `purchases`）。守卫同步 |
| **价值** | 回答"我还欠谁钱、多久要还、哪家供应商在涨价" —— 这是"钱漏在哪"的又一块 |

**字段（按 v0.2 §3.1，全部走 `field_def` / 表列，零 DDL）**：

| 类别 | 字段 |
|---|---|
| 档案 | 供应商名、主联系人+电话、副联系人+电话、**账期(天)**、**信用额度**、照片 |
| 单据 | 采购日期、品名、数量、单位、单价、**应付**、折价数量、**折价金额**、**实付**、**已付**、**待付** |
| **自动算** | **账期剩余天数**、**是否逾期**、**已用额度**、**剩余额度**、**配送时效**、**评级** |

**评级规则**（v0.2 §3.1.1，照抄）：
```
准时交付率 30% + 质量合格率 30% + 价格稳定性 20% + 损耗贡献 20%
A ≥ 90 / B ≥ 80 / C ≥ 70 / D < 70
```

**新增指标**：应付账龄结构（0-30/31-60/61-90/90+ 天）、逾期金额、供应商集中度（TOP1 占比）。

**验收**：造 3 家供应商，其中一家逾期 → 报告能说出「欠 3 家共 X 元，A 家还有 5 天到期，C 家已逾期 12 天」。
